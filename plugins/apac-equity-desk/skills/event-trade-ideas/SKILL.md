# Event Trade Ideas

Start only from a verified event/catalyst pack, not a headline list. Generate at most the few differentiated scenarios supported by evidence; zero is acceptable.

For each scenario provide name/ticker, event, prior market expectation, variant view, event-to-fundamentals-to-valuation transmission, possible expression (long/short/pair/basket as research language only), horizon, repricing catalyst, confirmation, invalidation, key risks and related A/H/ADR/supplier/customer/commodity/FX read-through. State what is already priced. Avoid sizing, execution or order instructions. Add the human-approval draft banner and educational-research disclaimer.
