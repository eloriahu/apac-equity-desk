# Parallel Earnings Review

Read `../../references/intent-routing.md`, `../../references/agent-team.md` and
`../earnings-review/SKILL.md`. Use this mode only when the automatic escalation
threshold is met.

## Capacity-aware waves

1. **Wave 1:** dispatch `filings-accounting-analyst` for reported numbers,
   reconciliation and accounting quality; `business-kpi-analyst` for segments,
   KPIs, guidance and operating change; and `industry-chain-analyst` for peers,
   end demand and supply-chain read-through.
2. **Wave 2:** give the normalized Wave 1 facts to
   `expectations-valuation-analyst` for consensus, estimate and valuation
   implications. Add `management-governance-analyst` only when management
   credibility, guidance delivery or capital allocation is material. Add
   `bear-case-analyst` for contested/high-consequence conclusions.
3. The desk head reconciles definitions and hands full packs to `chief-editor`.
   `desk-verifier` receives only the draft and packs; allow one revision.

Never run more workers concurrently than the environment permits. A four-slot
environment means the desk head plus at most three workers. Roles that are not
material to the question are omitted rather than run by default.

Give every role the same claim/source-ID registry with `origin` and
`independence_group`. Agent agreement never upgrades evidence confidence by
itself. Workers must not spawn workers or invoke another orchestration skill.

The final answer leads with the result and what changed, then bridges actuals
to consensus/prior, segments/margins, guidance, estimate/valuation implications,
peer read-through, contradictions and next evidence. Preserve reported,
adjusted, guidance, consensus, derived and assumed values separately.

Public Equity Investing owns a requested full model update automatically when
available; this team supplies verified APAC evidence. If it is unavailable,
state the boundary. Portfolio artifacts require an explicit portfolio request.
All work remains read-only and carries the human-approval banner.
