# Catalyst Analysis

Read `../../references/source-priority.md`. Define the observation, session and relevant comparison group. Build a timeline from the last unaffected price through each disclosure and market reaction. For every proposed catalyst record source level, freshness, specificity, market fit, whether it was already known and contradictory evidence.

Explain the transmission chain from event to revenue/cost/cash flow/risk premium and then to the security or peers. Do not confuse a structural vulnerability with today's trigger. Rank explanations high/medium/low using the shared evidence score; state `unresolved` if evidence does not discriminate. Preserve Level 4 claims only as attributed chatter and seek a company/exchange response. Return a draft conclusion, alternative explanation, read-through and the next fact that would confirm or falsify the view.
