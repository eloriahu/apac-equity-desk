# APAC Equity Desk 1.8.0

Adds shared tool selection to all 37 skill entrypoints, including direct invocation.

- Classify the question and evidence needs before selecting tools; inspect current-host availability, task coverage, timestamps, file access and runtime dependencies.
- A dependency-free selector chooses eligible candidates with source constraints, local-input boundaries, explicit preferences and failure fallbacks. It makes no network calls.
- Docling handles structured PDF intake; MarkItDown handles text conversion; spreadsheet tools preserve cell/formula semantics. Serena supports code navigation inside desk-development.
- An eligible connected read-only quote provider or official exchange source can fill missing fields when OpenBB is unavailable or lacks coverage. Supplied Bloomberg observations and original-source authority retain precedence.
- The lead accounts for each required need using actual results or a material gap before verification/editing. A planned tool call is not completed research.
- Synthetic regression cases exercise tool selection and failure handling. They do not measure model-level semantic routing accuracy; the selection guide defines a separate live-replay protocol for that claim.

No new MCP connection, dependency, subscription, brokerage mutation or publishing behavior is bundled. Japan EOD formatting and the existing research/calculation contracts are preserved.
