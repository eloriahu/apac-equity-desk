# APAC Equity Desk 1.10.0

Connects the question-driven research planner to the existing eleven native
agent roles in Codex and Claude Code. Each role can use multiple relevant
integrated skills and tools within a scoped assignment.

A shared protocol maps research modules to roles and requires complete briefs,
source/claim IDs, actual tool calls, completion checks and explicit gaps. Dependent
analysis waits for returned prerequisite packs. Workers without a connector can
request a scoped read-only call from the lead; permissions are not widened.

The lead reserves its own runtime slot and queues roles beyond available worker
capacity. Research feeds an editor, followed by a fresh-context verifier and the
existing single editorial revision. Simple requests remain lean, model settings
are inherited, and unavailable native agents produce a disclosed sequential
fallback rather than a claim of independent agent review.

Validation: 145 offline tests passed; all eleven role definitions parsed with
inherited models and unchanged tool allowlists. A Codex native-agent synthetic
run exercised accounting, business interpretation, editing and a fresh verifier.
The independent review passed within the offline scope, preserving limited
evidence readiness. The HTTP-only structural checker flagged local artifact
URLs; the verifier separately confirmed those local targets and reported the
helper limitation. Both clients installed identical 180-file plugin packages.
Claude native-agent execution and live market connectors were not smoke-tested.
