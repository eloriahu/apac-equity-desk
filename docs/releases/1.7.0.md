# APAC Equity Desk 1.7.0

Integrates optional source-extraction, scientific-research and development tools
into the existing desk workflows in Codex and Claude Code.

- Firecrawl supports public-source search and extraction; MarkItDown supports
  local document intake. Original sources, timestamps, locators and verification
  status remain attached to research claims.
- New statistical-research workflow selects installed K-Dense database-lookup,
  statistical-analysis, statsmodels and PyMC capabilities for empirical questions.
  Historical replay and assumption-driven deal sensitivity keep their existing
  owners and calculation contracts.
- New desk-development workflow selects Context7, Matt Pocock and gstack tools
  for implementing or maintaining desk software. Explicit-only skills keep that
  invocation policy; routine financial research does not start coding workflows.
- Added Claude Code `/empirical` and `/develop` shortcuts and Codex skill metadata.

The plugin does not bundle those projects, establish new connections or install
modeling packages. Current-session tool availability, library runtimes and data
entitlements are checked before use. Missing optional tools fall back to
available methods or a specific limitation. Conversion does not verify numbers,
refresh spreadsheet formulas or grant access to proprietary material. Modeling
does not establish causality, calibrated deal probabilities or a tradable return
without the required evidence and diagnostics.
