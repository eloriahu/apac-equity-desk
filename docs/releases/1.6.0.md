# APAC Equity Desk 1.6.0

Event-driven research is now part of the APAC desk's existing router. Announced
takeovers and special situations can progress from discovery and document review
to costed scenarios, sensitivity, historical replay and local alert evaluation.

## Added

- Merger arbitrage, special situations and deal-monitoring workflows, including
  cash/fixed-ratio stock/mixed scenarios, partial hedges, financing, borrow,
  rebates, dividends and net break-even probability.
- Deal radar with declared market/source coverage, as-of filtering, evidence
  deduplication and conflicting-primary-term review.
- Deal document extraction workflow and cited normalized term comparison,
  preserving unknowns and distinguishing omission from contractual deletion.
- Completion-probability, break-price and timing sensitivity grids.
- Consideration models for cash, stock, fixed-value collars, CVRs, partial-tender
  proration and explicit scenario FX, with payment-date discounting.
- Historical portfolio replay with locked capital, entry/exit costs, independent
  execution prices and marks, failed/unresolved deals, benchmark/drawdown and
  chronological segment reporting.
- Local alert evaluation for status/terms/consideration changes, spread widening,
  deadlines and stale data, with persisted duplicate suppression and rearming.

The six new focused workflows have matching Codex skills and Claude Code commands.
The original three event workflows and the existing market/fundamental desk
workflows remain available through natural-language routing.

## Use and validation

See the [README](../../README.md) and
[toolkit guide](../../plugins/apac-equity-desk/references/event-driven/toolkit.md)
for runnable synthetic examples, schemas, assumptions and limitations.

Validation covers arithmetic identities, collar boundaries, CVR discounting,
proration, point-in-time filtering, source conflicts, capital reuse, missing marks,
failed/unresolved outcomes and alert retries/rearming. All helpers run offline;
no new package, credential, data subscription or brokerage connector is required.

## Boundaries

Radar coverage depends on sources actually searched or supplied. Document
comparison consumes normalized extracts, not an automatic legal parser. Complex
consideration output is valuation NPV; it is not hedged trading P&L. Historical
testing is a fully funded long-only replay of supplied decisions, not a complete
stock-hedged merger-arbitrage simulator or an empirical performance claim. Alerts
evaluate local research state; live scheduling and delivery require a separately
configured monitor. Synthetic examples are not actual deals.

Version metadata is aligned across Codex, Claude Code and the Python project.
Codex's build suffix distinguishes its cached plugin build. Existing installations
receive these workflows when updated to the published release; editing this branch
alone does not upgrade an installed remote plugin.
